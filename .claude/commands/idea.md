description: Capture an idea into IDEAS.md (zero ceremony)
---

Append this idea to the **Inbox** section of `IDEAS.md` at the repo root: $ARGUMENTS

Rules:
- Give it the next free id (`T-n` for Token Town, `K-n` for the tracker; pick by what the
  idea is about, and if it's ambiguous just ask in one short line).
- Write it as a single table row: the user's idea in their own words, tightened only for
  grammar. Do not editorialize, do not expand it into a design, do not add caveats.
- If you can see an obvious size (S/M/L) add it; otherwise leave it blank rather than guess.
- If the idea is already in the file (any section), say so instead of duplicating it — and
  if it's in **Declined**, tell the user which reason it was declined for and ask whether
  they want to overturn it.
- Then confirm in one sentence: the id, and where it landed. Nothing else — this command is
  meant to cost the user five seconds.

Do not start building it. Capture only.
