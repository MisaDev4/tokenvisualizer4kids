Token Town — every 5 minutes, a house

The session is a town. Every 5-minute interval, whatever you build is that interval's house — it ranks up live (tent → shack → cabin → cottage → house → villa → manor → keep) while you work, then solidifies when the interval ends and construction moves to the next plot. Houses keep their model's color, breaks become trees, and the sky is synced to your actual local time and sunrise/sunset. This page opened mid-session: everything already standing was backfilled from “earlier” data — exactly what the app would do from its usage database.

How it maps to the app: intervals are 5-minute buckets over the same per-response rows the Live tab reads, one house per model per bucket, so opening the tab after five hours of work replays instantly into this exact town. Sky uses the Windows clock plus sunrise/sunset from your location (here: browser clock, solar approximation, optional geolocation). Hover any building for its receipt — which five minutes built it, with which model, and how many tokens. “Demo ×50” compresses time so you can watch a full evening; real time is the actual product behavior.
